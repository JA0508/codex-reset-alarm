# 界面设计约定

本项目是每天查看与操作的工具，不是营销落地页。用户明确偏好 Apple 原生产品的安静、紧凑与熟悉感。

## 信息顺序

1. 下一次刷新时间与剩余等待时间。
2. 当前赠送重置次数与可验证的到期信息。
3. 提醒开关，以及当前操作的结果。

连接地址与试听是辅助操作。主页不重复已经完成的手机设置教程，不声称知道手机是否已创建闹钟。

## 视觉规则

- 使用系统无衬线字体，时间启用 tabular-nums；不用额外展示字体或装饰性等宽字体。
- 单列、共同表面、分隔线组织信息；不把每个事实装进独立大卡片。
- 浅色以系统灰、白、深色文字为主，暗色跟随系统；蓝色用于动作，绿色用于开启状态。
- 不增加重复英文眉题、装饰时钟、渐变、发光、虚构图表或没有功能的动效。
- 按钮、开关、焦点与禁用状态使用一致的原生控件语言。手机触控目标保持可点选。
- 关闭提醒不等于额度失效，因此不把仍在更新的倒计时灰掉。

## 验证

每次改动检查桌面与手机、浅色与暗色、加载失败、提醒开关和连接面板。演示必须显示模拟数据标记，不能影响真实提醒。

方法参考：[Impeccable](https://github.com/pbakaus/impeccable) 的 Operate 界面准则；本项目没有运行或分发其安装器与二进制。此约定用于约束本项目后续设计，不代表与 Apple 或 Impeccable 存在隶属关系。
